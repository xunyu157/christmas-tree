# 🎄 客制化 3D 星空粒子圣诞树（Custom Christmas Tree）

一个高颜值、手机与电脑端均流畅运行的 **3D 发光碎钻粒子客制化圣诞树** 网页项目。  
无需任何后端服务器与数据库，定制完成后即可一键生成**专属分享链接 / 二维码**或**导出高清贺卡图片**送给重要的人！

---

## ✨ 功能亮点

- **5 套精选主题色板 + 自由取色**：默认内置「粉紫碎钻金」浪漫配色，以及「经典祖母绿金」「冰雪星河蓝」「香槟鎏金夜」「极光幻梦紫」，还支持树身、碎钻高光、丝带、树顶、底部漩涡独立调色。
- **3 种树顶发光粒子造型**：💖 发光爱心 / ⭐ 经典五角星 / ❄️ 冰晶雪花 一键切换。
- **丰富动态特效自由组合**：
  - 🎆 绚丽 3D 粒子烟花（自动绽放 + **点击夜空任意位置手动放烟花**）
  - 🎗️ 金色星光螺旋丝带
  - 🌀 底部星河漩涡与月光雾晕
  - ❄️ 漫天轻盈飘雪 & 🌌 四角星芒星空
  - 🌟 电影级梦幻辉光（Bloom 强度可调）
  - 🔄 360° 自动旋转 + 鼠标/手指自由拖拽缩放
- **专属双行祝福文字**：自定义中文主祝福、英文花体副标题、落款署名、字体风格与发光颜色。
- **零后端分享闭环**：
  - 一键复制专属链接或生成二维码，朋友打开自动进入纯净无按钮的**「礼物观赏模式」**。
  - 一键保存包含圣诞树与发光祝福文字的高清 PNG 贺卡图。

## 🚀 本地运行指南（新手一步步跟着做）

你的电脑已安装 Node.js，只需在项目文件夹打开终端，输入下面两条命令：

```bash
# 1. 安装依赖（第一次运行执行一次即可）
npm install

# 2. 启动本地预览服务器
npm run dev
```

终端会显示一个本地地址（例如 `http://localhost:5173`），在浏览器里打开就能看到你的圣诞树！修改代码保存后页面会自动实时刷新。

## 🌐 免费上线教程（生成手机微信可直接打开的公网网址）

无需买服务器、0 元永久托管，推荐以下两种最简单的方式：

### 方式一：Vercel 一键上线（最省心，3 分钟搞定）
1. 在 [GitHub](https://github.com) 新建一个仓库，把本文件夹代码上传上去。
2. 打开 [vercel.com](https://vercel.com) 用 GitHub 账号登录。
3. 点击 **Add New → Project**，选中你的圣诞树仓库，保持默认设置直接点 **Deploy**。
4. 等待约 30 秒，Vercel 会给你一个专属 `https://xxx.vercel.app` 链接，直接发微信就能打开！

### 方式二：GitHub Pages 免费托管
1. 在终端运行构建命令，生成静态网页产物：
   ```bash
   npm run build
   ```
2. 把生成的 `dist/` 目录发布到 GitHub Pages（或配置 GitHub Actions 自动部署），即可获得 `https://<你的用户名>.github.io/<仓库名>/` 网址。

## 📁 代码目录说明（方便新手阅读与魔改）

```text
christmas-treeai/
├── index.html                  # 页面骨架：画布、双行祝福语、定制面板与二维码弹窗
├── package.json                # 项目依赖（vite、three、qrcode）
├── vite.config.js              # 打包配置（已适配子路径部署）
└── src/
    ├── main.js                 # 总入口：串联分享解码、3D 引擎与控制面板
    ├── config/
    │   └── presets.js          # 5 套配色预设与默认配置（想加新配色改这里！）
    ├── scene/
    │   ├── ChristmasApp.js     # Three.js 总控：相机、触控旋转、辉光与点击放烟花
    │   ├── TreeBuilder.js      # 碎钻粒子圣诞树 + 螺旋星光丝带
    │   ├── TopperBuilder.js    # 树顶 3D 发光爱心 / 五角星 / 雪花
    │   ├── GroundVortex.js     # 底部星河漩涡与雾光底座
    │   ├── FireworksSystem.js  # 3D 粒子烟花系统
    │   ├── AtmosphereSystem.js # 闪烁星空、四角星芒与飘雪
    │   └── particleTexture.js  # 程序化光斑、星芒与雾晕贴图
    ├── ui/
    │   └── ControlPanel.js     # 定制抽屉面板交互逻辑
    ├── utils/
    │   ├── share.js            # 零后端 URL 编解码工具
    │   └── snapshot.js         # 高清贺卡 PNG 合成导出
    └── styles/
        └── main.css            # 暗夜毛玻璃样式与手机/桌面自适应排版
```
